# My-Blog

Página do meu primeiro blog desenvolvido durante meus estudos de **HTML, CSS e JavaScript**.

## 🌐 Projeto

**Localhost:** em desenvolvimento

## 🚀 Atualização atual

Nesta versão, foram adicionados:

* ❤️ Botão de Like/Reação
* 📝 Novos posts
* 🌙 Tema claro e escuro
* ⬆️ Botão para voltar ao topo
* 🎨 Variáveis CSS para personalização das cores
* ✨ Efeito `hover` nos cards dos posts
* 🔗 Links no nome do autor e na imagem
